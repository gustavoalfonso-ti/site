## 🇧🇷 Contribuindo para o Agente de Atualização do LinkedIn

Obrigado por considerar contribuir para este projeto! Aqui estão algumas diretrizes para ajudá-lo.

### Como Contribuir

1. **Fork o repositório**
2. **Crie uma branch** para sua feature (`git checkout -b feature/nova-funcionalidade`)
3. **Faça suas alterações**
4. **Execute os testes** (`python3 test_linkedin_agent.py`)
5. **Commit suas mudanças** (`git commit -am 'Adiciona nova funcionalidade'`)
6. **Push para a branch** (`git push origin feature/nova-funcionalidade`)
7. **Abra um Pull Request**

### Diretrizes de Código

- Siga o estilo PEP 8 para código Python
- Adicione docstrings bilíngues (PT/EN) para todas as funções públicas
- Mantenha a cobertura de testes
- Atualize a documentação quando necessário

### Executando Testes

```bash
# Executar todos os testes
python3 test_linkedin_agent.py

# Verificar sintaxe
python3 -m py_compile linkedin_agent.py linkedin_scheduler.py
```

### Ideias para Contribuição

- [ ] Suporte para upload de imagens em posts
- [ ] Suporte para upload de vídeos
- [ ] Agendamento com cron integrado
- [ ] Interface web para gerenciar posts
- [ ] Suporte para múltiplas contas
- [ ] Analytics de posts publicados
- [ ] Integração com outras redes sociais
- [ ] Geração de conteúdo com IA
- [ ] Suporte para LinkedIn Pages (empresas)
- [ ] Respostas automáticas a comentários

### Reportando Bugs

Ao reportar bugs, inclua:
- Versão do Python
- Sistema operacional
- Passos para reproduzir o bug
- Mensagens de erro completas
- Logs relevantes

### Segurança

Se você encontrar uma vulnerabilidade de segurança, **NÃO** abra uma issue pública. 
Entre em contato diretamente com os mantenedores do projeto.

## 🇺🇸 Contributing to LinkedIn Update Agent

Thank you for considering contributing to this project! Here are some guidelines to help you.

### How to Contribute

1. **Fork the repository**
2. **Create a branch** for your feature (`git checkout -b feature/new-feature`)
3. **Make your changes**
4. **Run the tests** (`python3 test_linkedin_agent.py`)
5. **Commit your changes** (`git commit -am 'Add new feature'`)
6. **Push to the branch** (`git push origin feature/new-feature`)
7. **Open a Pull Request**

### Code Guidelines

- Follow PEP 8 style for Python code
- Add bilingual docstrings (PT/EN) for all public functions
- Maintain test coverage
- Update documentation as needed

### Running Tests

```bash
# Run all tests
python3 test_linkedin_agent.py

# Check syntax
python3 -m py_compile linkedin_agent.py linkedin_scheduler.py
```
